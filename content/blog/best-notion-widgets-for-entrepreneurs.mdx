## How do I add a Blocs widget to my Notion workspace?

Add a Blocs widget to Notion by copying the widget's embed URL (e.g., blocs.me/pomodoro), pasting it into a Notion page, and selecting "Embed" from the link menu. The widget then renders live inside the page, no code or plugin install required.

1. Go to the widget page (e.g., [Pomodoro Timer](https://blocs.me/pomodoro-timer)) and copy the embed URL.
2. In Notion, type `/embed` and paste the link.
3. Resize the embed block to fit your dashboard layout.
4. Repeat for other widgets like the [Habit Tracker](https://blocs.me/habit-tracker-widget) or [Progress Bar](https://blocs.me/progress-bar-widget).
