## How do I add these widgets to a shared Notion page?

Copy a widget's embed URL from Blocs, paste it into a Notion page using the "/embed" block, and resize it. Both partners see live updates if the page is shared, since the widget is an iframe pulling from Blocs, not a static image.

1. Open the widget page (e.g., [habit tracker](https://blocs.me/habit-tracker-widget)) and copy its embed link.
2. In your shared Notion page, type `/embed` and paste the link.
3. Resize the block so it fits next to your other widgets.
4. Repeat for additional widgets (timer, countdown, calendar) on the same page.
5. If using Pro, sign in via [sign-in](https://blocs.me/sign-in) so settings sync across both partners' devices.

## FAQs

### Do both partners need to pay for Blocs Pro?

No. Blocs Pro is tied to the account that purchases it, and that account's widgets sync across devices. If you're sharing one Notion page, one partner's $17 purchase unlocks the Pro widgets embedded on that page.

### Can we use these widgets if we're long-distance?

Yes. Because widgets are embedded iframes with Pro cloud sync, both partners can view the same habit tracker, countdown, or calendar from different devices and locations, as long as they're viewing the same shared Notion page.

### Is there a dedicated "couples" widget?

Not yet. Blocs doesn't currently offer a widget built specifically for couples (like a shared mood tracker or relationship journal), but habit, countdown, and calendar widgets cover most of the same use cases and a dedicated couples widget may be added in the future.

### How much does Blocs Pro cost?

Blocs Pro is a $17 one-time payment, not a recurring subscription. It unlocks every Pro widget (countdown, calendar, clock, progress bar, weather, quote of the day) plus analytics, theming, and cloud sync, with full details on the [pricing page](https://blocs.me/pricing).

### Do I need to install anything?

No. Every Blocs widget is a web-based embed added through Notion's native "/embed" block, so there's nothing to install on either partner's device.

### Can we mix free and Pro widgets on the same page?

Yes. A shared Notion page can combine free widgets (habit tracker, water tracker) with Pro widgets (countdown, calendar) side by side; there's no restriction on mixing tiers on one page.
