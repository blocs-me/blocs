## What Does a Reading Tracker in Notion Look Like?

A Notion reading tracker is a database where each row is a book. You assign properties like Status (To Read, Reading, Finished), Pages Read, Total Pages, Star Rating, Genre, and Start/Finish Date. Views let you slice that data into a reading list, a finished shelf, or a stats dashboard, all in one workspace.

The native database approach is powerful for cataloguing books, but it doesn't push you to actually read every day. That accountability gap is where embedded widgets make a real difference. Combining both is the most effective setup.

## How to Set Up a Reading Database in Notion?

Create a new full-page database in Notion and add the following properties. This takes about five minutes and requires no template download.

### Step 1: Create the database

1. Open Notion and type `/database`, then choose **Table – Full page**.
2. Name it "Reading List" or "Books 2026".

### Step 2: Add core properties

| Property Name | Type | Purpose |
|---|---|---|
| Title | Title (default) | Book name |
| Author | Text | Author name |
| Status | Select | To Read / Reading / Finished / Abandoned |
| Pages Read | Number | Track progress through the book |
| Total Pages | Number | Used to calculate % complete |
| Rating | Select (★ to ★★★★★) | Personal score after finishing |
| Genre | Multi-select | Filter by category |
| Date Started | Date | Track how long each book took |
| Date Finished | Date | Calculate reading speed over time |

### Step 3: Add a Formula property for % progress

Add a **Formula** property named "Progress". Use this formula:

```
round(prop("Pages Read") / prop("Total Pages") * 100)
```

This gives you a clean percentage for each book you're currently reading.

### Step 4: Create useful views

- **Board view (grouped by Status)**: See your whole library at a glance, similar to Goodreads shelves.
- **Gallery view (filtered to "Finished")**: A visual "books I've read" shelf.
- **Table view (filtered to "Reading")**: Focus only on active books.
- **Gallery view (filtered to "To Read")**: Your backlog queue.

Notion's native progress display is limited to numbers and text. ## FAQs

### Can you track pages read per day in Notion?

Yes. Add a "Pages Read Today" number property to your active book entry and update it daily. You can also create a separate "Daily Reading Log" database with Date and Pages columns, then use a Rollup in your book database to sum total pages read. It's manual but effective inside Notion's native toolset.
