## Why Use a Meditation Timer Inside Notion?

Most people use a separate app for meditation and Notion for notes, tasks, or journaling. That context switch is a small but real friction point: you close Notion, open an app, meditate, come back, try to remember what you were doing. Embedding a timer directly on your Notion page removes that step. Your intention, reflection prompts, or meditation log can sit right next to the timer itself.

There's also the accountability angle. If your meditation habit tracker, daily journal, and timer are all on the same page, you're far more likely to actually use them together.

## How to Add a Meditation Timer to Notion

### Step 1: Get the Widget URL

Go to [blocs.me/pomodoro-timer](https://blocs.me/pomodoro-timer). You'll see the live widget — a clean, minimal timer with configurable work and break sessions. The embed URL is `https://blocs.me/pomodoro`.

### Step 2: Embed It in Notion

1. Open the Notion page where you want the timer.
2. Type `/embed` and select the Embed block.
3. Paste `https://blocs.me/pomodoro` and click "Embed link."
4. Resize the block as needed — taller is better for this widget.

### Step 3: Set It Up for Meditation

The free version uses default Pomodoro intervals (25 min work, 5 min break). For a dedicated meditation setup — say, a 10 or 20 minute session — upgrade to Pro to unlock custom durations. You can set any session length you want and it'll persist across devices via cloud sync.

### Step 4: Build a Meditation Page Around It

Pair the timer with a simple Notion setup: a daily log (toggle list or database), a few reflection prompts as text blocks, and optionally a [Habit Tracker widget](https://blocs.me/habit-tracker-widget) to mark off consecutive days. Everything stays in one workspace.

## FAQs

### Can I use a meditation timer in Notion for free?

Yes. Blocs' Pomodoro Timer embeds in Notion at no cost and requires no account. The free version uses default session lengths. If you need a custom duration (e.g., a 20-minute meditation), that requires the Pro plan at $17 one-time.

### Does Notion have a built-in meditation timer?

No. Notion has no native timer functionality. You need to embed a third-party widget using Notion's iframe embed block. Blocs is designed specifically for this use case.

### How do I embed a timer in Notion?

Type `/embed` in any Notion page, paste the widget URL (e.g., `https://blocs.me/pomodoro`), and click "Embed link." The timer appears inline and is fully interactive.

### Will the timer work on mobile Notion?

Embed blocks in the Notion mobile app have limited interactivity depending on your device and Notion version. For the best experience, Blocs widgets are designed for desktop use inside Notion. The widgets themselves are mobile-responsive if accessed directly in a browser.

### Can I track my meditation streak in Notion?

With Blocs Pro, the [Habit Tracker widget](https://blocs.me/habit-tracker-widget) includes streak tracking, daily/weekly/monthly analytics, and cloud sync — so your progress persists across sessions. Pair it with the Pomodoro Timer on the same Notion page for a complete meditation dashboard.

### Is there a dedicated meditation timer widget, or do I use a Pomodoro timer?

Blocs doesn't currently have a standalone meditation-specific timer, but the Pomodoro Timer covers the same core functionality: a countdown session with a visual display. With Pro, you can set any duration — making it work for 5-minute breathing exercises or 45-minute deep focus sessions alike. A dedicated ambient meditation mode is something Blocs is exploring for a future update.
