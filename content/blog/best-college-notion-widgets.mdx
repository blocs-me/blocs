## How Do You Embed a Widget in Notion?

Embedding a Blocs widget in Notion takes about 30 seconds and requires no technical setup.

1. Go to the widget page on [blocs.me](https://blocs.me) (e.g., `blocs.me/pomodoro`)
2. Copy the embed URL
3. In Notion, type `/embed` and select the Embed block
4. Paste the URL and click "Embed link"
5. Resize the block to fit your dashboard layout

That's it. The widget is now live and interactive inside your Notion page. No browser extensions, no API keys, no configuration outside of Notion.
