## How do you set a native reminder in Notion?

Type `@remind` or `/remind` inside any page, then pick a date and time from the calendar that pops up. Notion inserts a mention that triggers a notification at that exact moment, but only once, on that specific date ([Notion Help Center](https://www.notion.so/help/reminders)).

### Step-by-step: setting a one-time reminder

- Open any page or block where you want the reminder to live.
- Type `@` followed by "remind" or use the `/remind` slash command.
- Select a date and, optionally, a time.
- Notion highlights the mention in red once it's overdue, and sends a notification if you have desktop or mobile notifications enabled.

This works well for one-off deadlines, but it has no "repeat every day" setting, so you'll need a workaround for recurring reminders ([Notion Help: Notifications](https://www.notion.so/help/mobile-and-desktop-notifications)).

## How do you make a reminder repeat every day in Notion?

Notion has no native "repeat daily" toggle, so recurring reminders require either a database template that auto-generates a new entry each day, or a third-party automation tool (like Zapier or Make) that resets the `@remind` date on a schedule. Both options take setup time and ongoing maintenance.

The most common database-based workaround:

- Create a database (e.g., "Daily Reminders") with a Date property.
- Open any entry, click the "..." menu, and set it as the default template with "Repeat" turned on in the template settings (available on paid Notion plans with recurring templates enabled).
- Each day, Notion duplicates the template entry with a fresh date and reminder mention.

If that feels like overkill for a simple daily nudge, like "drink water" or "do today's habit check-in", a persistent visual widget on your dashboard is a lower-maintenance alternative.

## FAQs

### Can I set a recurring daily reminder natively in Notion?

Not with a simple toggle. Notion's `@remind` command is one-time only; recurring reminders require a database template with repeat settings or a third-party automation tool like Zapier ([Notion Help Center](https://www.notion.so/help/reminders)).

### Will Notion send me a push notification for my reminder?

Yes, if you've enabled mobile or desktop notifications in Notion's settings and the reminder date/time has passed, Notion sends a push alert ([Notion Help: Notifications](https://www.notion.so/help/mobile-and-desktop-notifications)).
