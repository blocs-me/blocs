## How to Set Up a Period Tracker Database in Notion

Create a new Notion database and add the following properties. This covers the essentials for a functional cycle log without overcomplicating the setup.

### Step 1: Create a new database

In any Notion page, type `/database` and select "Table – Full page." Name it something like "Cycle Log" or "Period Tracker."

### Step 2: Add the right properties

Delete the default "Tags" property and replace it with these:

| Property Name | Property Type | What It Tracks |
|---|---|---|
| Date | Date | The specific day you're logging |
| Cycle Day | Number | Day 1 = first day of period |
| Flow | Select | None / Spotting / Light / Medium / Heavy |
| Symptoms | Multi-select | Cramps, Bloating, Headache, Fatigue, Acne, etc. |
| Mood | Select | Great / Good / Okay / Low / Irritable |
| Energy | Select | High / Medium / Low |
| Notes | Text | Free-form observations |

### Step 3: Add a calendar view

Click "Add a view" and select "Calendar," using the "Date" property. This gives you a visual monthly overview of your cycle at a glance. Keep the table view as your primary data entry point and the calendar as a read-only summary.

### Step 4: Add a filtered view for period days

Create a second table view filtered to show only rows where "Flow" is not "None." Name it "Period Days Only." This lets you quickly calculate cycle length by comparing the first date of each period cluster.

### Step 5: Calculate your cycle length manually

Notion doesn't do date arithmetic automatically in databases without formulas. Add a "Formula" property named "Days Since Last Period" and use Notion's `dateBetween()` formula referencing your Date property and a hardcoded reference date. You'll need to update the reference date each cycle start, which is a limitation of this approach.

## What to Track During Each Cycle Phase?

Tracking more than just period start/end dates gives you actionable patterns over time. Here's a phase-by-phase breakdown of useful data points:

| Phase | Approximate Days | Useful Things to Log |
|---|---|---|
| Menstrual | Days 1-5 | Flow level, cramps intensity, fatigue, mood |
| Follicular | Days 6-13 | Energy, motivation, skin clarity, appetite |
| Ovulatory | Days 14-16 | Discharge changes, libido, social energy |
| Luteal | Days 17-28 | PMS symptoms, bloating, mood shifts, sleep quality |

You can add "Phase" as a Select property in your Notion database and fill it in manually each entry, or tag entries retroactively once you know your average cycle length. Tracking these over 3+ months often reveals patterns (for example, consistently low energy on days 20-23) that help with planning workouts, social commitments, and rest days. ## FAQs

### Does Notion have a built-in period tracker?

No. Notion does not include a native period tracking feature. You need to build a database manually or use an embedded widget. The setup described in this guide uses a Notion database for logging and an optional embedded habit tracker widget for daily tracking without switching apps.

### Can Notion predict my next period?

Not automatically. Notion databases don't generate predictions without custom formulas or third-party automation tools like Zapier. You can approximate predictions manually by tracking cycle length over several months and noting the average. For automated predictions, a dedicated app like Clue or Flo works better alongside your Notion log.
