## How Do You Build an Assignment Tracker in Notion?

Create a new database (table view) with these properties: Name (the assignment), Subject (select), Due Date (date), Status (select: Not Started / In Progress / Done), and Priority (select: High / Medium / Low). Filter by status to see only active work. Sort by due date so the most urgent items are always at the top.

### Step-by-step setup

1. Create a new page and choose **Table** as the view type.
2. Rename the default "Name" column to "Assignment".
3. Add a *Select* property called "Subject" and add your classes as options.
4. Add a *Date* property called "Due Date".
5. Add a *Select* property called "Status" with options: Not Started, In Progress, Done.
6. Click **Filter** and hide rows where Status = Done so the table stays clean.
7. Sort by Due Date (ascending) so urgent work surfaces automatically.

One tip: add a *Formula* property called "Days Left" using `dateBetween(prop("Due Date"), now(), "days")`. It shows exactly how many days remain, which makes priority obvious at a glance.

## How Do You Set Up a Subject Hub in Notion?

A subject hub is a top-level page for each class that holds everything related to it: lecture notes, readings, past exams, and a filtered view of your assignment tracker showing only that subject's tasks. This prevents scattered notes and means you always know where to go before a study session.

### What to include in each subject page

- **Linked database view**: A filtered view of your assignment tracker (filter: Subject = this class).
- **Notes section**: Sub-pages per lecture or topic, organized by week or unit.
- **Resources**: Links to syllabi, textbook PDFs, course websites.
- **Key dates**: Exam dates, drop deadlines, project milestones.

Use a *toggle* block to collapse older weeks of notes so the page doesn't feel overwhelming as the semester goes on.

## How Do You Create a Weekly Study Schedule in Notion?

Build a simple table with days of the week as columns and time blocks as rows. Block study sessions directly in the cells alongside fixed commitments (classes, work). Alternatively, use a linked calendar view of your assignment database to see deadlines visually by week.

### Two approaches compared

| Approach | Best for | Setup time |
|---|---|---|
| Simple weekly table | Visual time-blockers who prefer a grid | 5 minutes |
| Calendar view of assignment DB | Deadline-driven students who want task context | 2 minutes (if DB exists) |

The calendar view is usually more useful because it connects directly to your real tasks rather than being a separate document you have to keep in sync.
