## How to Add Widgets to Your Notion Student Dashboard

1. **Open your Notion dashboard page.** If you don't have one, create a new page and title it "Dashboard" or "Home."
2. **Type `/embed` in a Notion block.** Select the "Embed" option from the menu that appears.
3. **Paste the widget URL.** For example, paste `https://blocs.me/pomodoro` for the Pomodoro timer.
4. **Click "Embed link."** The widget loads inline. Resize it by dragging the edges.
5. **Repeat for other widgets.** Arrange them in columns using Notion's column layout.

No code, no API keys, no developer setup required. If you can paste a URL, you can embed a Blocs widget.
