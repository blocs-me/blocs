## How to Add a Pomodoro Timer to Notion

The Blocs Pomodoro timer is free, requires no sign-up, and embeds in a single step. Here's the full process:

### Step 1: Open your Notion page

Navigate to the Notion page where you want the timer to live. This can be a study dashboard, a work sprint board, or any personal workspace page.

### Step 2: Add an embed block

Type `/embed` in the page body and select the **Embed** block from the menu that appears. Notion will prompt you to paste a URL.

### Step 3: Paste the Blocs timer URL

Copy the Blocs Pomodoro embed URL:

`https://blocs.me/pomodoro`

Paste it into the embed field and press **Embed link**. The timer will appear inline on your page immediately.

### Step 4: Resize the widget

Click and drag the edges of the embed block to resize it. The Pomodoro timer looks best at around 400px wide. You can move it anywhere on the page, including inside columns.

That's it. The [Blocs Pomodoro timer](https://blocs.me/pomodoro-timer) starts immediately — 25-minute work sessions, 5-minute short breaks — with no configuration required.

## FAQs

### Does the Blocs timer work on mobile Notion?

Embed blocks render in the Notion mobile app, but interaction can be limited depending on your device and Notion version. The experience is most reliable on desktop and in the Notion web app. For mobile-first use, opening the widget URL directly in a browser is an option.

### Do I need to create an account to use the free timer?

No. The free Blocs Pomodoro timer works without any sign-up. Just paste the embed URL and start using it. An account is only needed if you upgrade to Pro for cloud sync and analytics.

### Can I use multiple timers on the same Notion page?

Yes. You can add multiple embed blocks to a single Notion page. For example, you could place a Pomodoro timer in a focus section and a Countdown timer in a project deadlines section — each using a separate embed block.

### Will the timer reset if I refresh my Notion page?

The free timer resets on page refresh since it has no persistent state. Blocs Pro users get cloud sync, so your session data and streaks persist across refreshes and devices.

### Is there a free countdown timer for Notion?

The Blocs Countdown Timer is a Pro feature. The free tier includes the Pomodoro timer, water tracker, and habit tracker. ### How is this different from building a timer in a Notion database?

A Notion database can record time entries and calculate durations after the fact, but it cannot count down in real time or alert you when a session ends. An embedded widget runs live in the browser, which is what makes it a functional timer rather than a log.
